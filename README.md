# The Norwood Files — Companion Workbooks

## Official Companion Resources

This repository contains the official companion workbooks supporting **The Norwood Files**.

**The Norwood Files**  
*A Novel About Risk, Audit and Root Cause in a Factory That Stopped Pretending*

## Purpose
The companion workbooks provide practical tools, templates and registers referenced throughout the book.

They are designed to help readers apply the methods presented in real operational environments.

## Available Workbooks

The official companion workbooks are maintained in:

[Companion-Workbooks](https://github.com/thenorwoodfiles/Norwood-Resources/blob/main/Companion-Workbooks)

Current resources include:

- Risk Register Workbook
- Finding Register Workbook
- Candidate Register Workbook
- Knowledge Inventory Workbook
